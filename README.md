# Hello Carbon 11 Web Components with Vue 3 (Archived)

This repository was created to demonstrate how to integrate **Carbon 11 Web Components** into a Vue 3 application.  
It showcases examples of best practices, component usage, and integration with modern tooling such as Vite, Pinia, i18next, and Cypress.
